# Проверка сценариев ViWork

Команды из каталога `frontend`:

```sh
npm ci
npx playwright install firefox
npm run test:e2e
```

Для тестов нужен установленный Google Chrome; Firefox скачивает Playwright.
В CI обе браузерные среды ставятся командой `npx playwright install --with-deps chrome firefox`.
Тесты поднимают Vite на `127.0.0.1:4179` и перехватывают API. Живая база,
ключи и сетевые вызовы моделей не нужны.

`data/contracts/problematic/problematic_01_multiple_violations.docx`.
Не используйте реальные договоры и персональные данные в фикстурах, Git и отчётах QA.

## Проверка удобства с пятью участниками

1. Пригласить пять пользователей, выдать тестовые аккаунты и один синтетический договор. Сохранять только обезличенные номера участников и наблюдения.
2. Дать задание без инструкции по кнопкам: войти, проверить файл, найти критическое замечание, открыть его цитату и норму, скачать отчёт, открыть тот же результат из истории.
3. Не подсказывать во время задания. Отметить время, ошибку или место остановки, факт подсказки и завершение. Отдельно спросить, чем отличается технический сбой от замечания к договору.
4. Принять критерий: не менее четырёх из пяти проходят сценарий без подсказок. По наблюдениям составить список правок и повторить затронутые шаги.
